# Revitget

#### 介绍

这是一个复刻前人基础上做的一个revit导出gltf的开源库，支持revit2020~revit2023。

**在线查看案例：** https://wangjinlei1.github.io/Revitget/

#### 支持

1、支持revit带材质导出GLTF

2、支持导出revit法向量、UV

3、支持draco多线程压缩

4、支持相同构件合并

5、支持导出gltf/glb

6、支持导出revit属性

#### Web 查看器 

- **功能**：支持加载 GLB 模型、360度旋转、缩放、HDR 环境光照。
- **说明**：为减小仓库体积，已移除内置示例模型与贴图资源；可在页面内直接上传本地模型文件进行预览。
